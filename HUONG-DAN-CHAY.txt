CÁCH 1: KHỞI CHẠY NHANH NHẤT (KHUYẾN NGHỊ CHO NGƯỜI DÙNG / GIẢNG VIÊN)
--------------------------------------------------------------------
1. Đảm bảo máy tính có cài đặt Node.js (tải miễn phí tại https://nodejs.org).
2. Nhấn đúp chuột (Double Click) vào file:
      👉 CHAY-NGAY.bat
   (Hoặc file "run-web.bat")

-> Trình duyệt web sẽ tự động mở ứng dụng tại địa chỉ:
      http://localhost:5173
-> Ứng dụng đã được đóng gói sẵn (Built), khởi chạy ngay trong 1 giây mà KHÔNG cần phải tốn thời gian tải thư viện hay cấu hình gì thêm!


CÁCH 2: DÀNH CHO LẬP TRÌNH VIÊN MUỐN SỬA ĐỔI CODE (DEV MODE)
--------------------------------------------------------------------
1. Nhấn đúp chuột vào file:
      👉 CHAY-DEV-(CHINH-SUA-CODE).bat
2. File này sẽ tự động chạy "npm install" và "npm run dev" với tính năng tự cập nhật code tức thì (Hot-Reload).

CÁC PHÍM TẮT THAO TÁC NHANH TRÊN MÀN HÌNH:
--------------------------------------------------------------------
- Phím [ F11 ]     : Bật chế độ Toàn màn hình (Presentation Mode).
- Phím [ D ]       : Bật chế độ Đạo diễn (Director Mode - tự động chạy kịch bản mẫu trong 90s).
- Phím [ B ]       : Bật / tắt Bản đồ quy trình BPMN 2.0 toàn màn hình.
- Phím [ 1 – 5 ]   : Chuyển đổi nhanh 5 bàn làm việc (1: Sinh viên, 2: Hệ thống tự động, 3: Cố vấn, 4: CTSV, 5: BGH).
- Phím [ Space ]   : Tạm dừng / Tiếp tục diễn tiến.
- Phím [ T ]       : Tua +1 ngày làm việc.
- Phím [ Shift+T ] : Tua +3 ngày làm việc (kích hoạt chuông điện thoại SLA quá hạn).
- Phím [ M ]       : Bật / tắt âm thanh tiếng gõ máy chữ, đóng dấu cơ học.
- Phím [ ? ]       : Bật bảng trợ giúp chi tiết.
