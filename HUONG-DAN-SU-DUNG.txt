CÁCH KHỞI CHẠY (DÀNH CHO NGƯỜI NHẬN FILE KHÔNG CÓ CÔNG CỤ ĐẶC BIỆT):
--------------------------------------------------------------------
1. Đảm bảo máy tính có cài đặt Node.js (tải miễn phí tại https://nodejs.org).
2. Nhấn đúp chuột (Double Click) vào file:
      👉 CHAY-DU-AN.bat  (hoặc CHAY-NGAY.bat / run-web.bat)

-> Trình duyệt web sẽ tự động mở ứng dụng tại địa chỉ:
      http://localhost:5173
-> Ứng dụng đã được đóng gói sẵn (Built), khởi chạy ngay trong 1 giây mà KHÔNG cần phải tốn thời gian tải thư viện hay cấu hình gì thêm!


CÁCH DÀNH CHO LẬP TRÌNH VIÊN MUỐN SỬA ĐỔI CODE (DEV MODE):
--------------------------------------------------------------------
1. Nhấn đúp chuột vào file:
      👉 CHAY-DEV-(CHINH-SUA-CODE).bat
2. File này sẽ tự động chạy "npm install" và "npm run dev" với tính năng tự cập nhật code tức thì (Hot-Reload).

CÁC PHÍM TẮT THAO TÁC TRÊN MÀN HÌNH:
--------------------------------------------------------------------
- [ F11 ]     : Toàn màn hình (Presentation Mode).
- [ D ]       : Bật chế độ Đạo diễn (Director Mode - tự động chạy demo trong 90s).
- [ B ]       : Bật / tắt Bản đồ quy trình BPMN 2.0 toàn màn hình.
- [ 1 – 5 ]   : Chuyển đổi nhanh giữa 5 bàn làm việc.
- [ Space ]   : Tạm dừng / Tiếp tục diễn tiến.
- [ T ]       : Tua +1 ngày làm việc.
- [ Shift+T ] : Tua +3 ngày làm việc (kích hoạt cảnh báo SLA).
- [ M ]       : Bật / tắt âm thanh cơ học retro.
- [ ? ]       : Bật bảng trợ giúp phím tắt.
